DARK ZONE PACKAGE

Files:
- dark.html
- darkzonequestions.html
- darkzone.css
- darkzonequiz.js

Important:
1. Keep your existing canonical nexus-quiz.css in the same project folder.
2. Keep dark2.png.png in the same project folder (used as the Dark Zone background).
3. Keep avatar-1.png.jpg / your avatar files in the same location used by Home.
4. Open dark.html from Home when the player selects Dare Zone.

Modes:
- Easy: 20 challenges
- Medium: 20 challenges
- Hard: 20 challenges
- Random: 20 random challenges from all 60

Dark Zone is intentionally more interactive/energetic than the other categories while still using the same NEXUS visual system.
All challenges are harmless and designed for fun.
