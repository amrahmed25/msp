# طبيبك | Tabibak

واجهة أمامية تجريبية عربية RTL للبحث عن الأطباء وتجربة تدفق الحجز. جميع بيانات الأطباء والأسعار والتقييمات والمواعيد افتراضية ولا تمثل معلومات طبية موثقة.

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `Tabibak`.
3. افتح `index.html` في متصفح حديث. للحصول على تجربة أكثر ثباتًا، شغّل خادم ملفات محليًا من المجلد (مثل Live Server في VS Code).
4. يعتمد تحميل تنسيقات Tailwind الحالية على CDN، لذا يلزم اتصال بالإنترنت لظهور هذه التنسيقات كما صُممت.

## الصفحات
- `index.html`: الصفحة الرئيسية والبحث والأطباء المقترحون.
- `pages/doctors.html`: قائمة الأطباء والبحث والفلاتر والترتيب.
- `pages/doctor.html`: الملف الشخصي لطبيب حسب المعرّف `id`.
- `pages/booking.html`: نموذج تجربة حجز حسب `doctorId`.
- `pages/login.html` و`pages/register.html`: واجهات جلسة تجريبية فقط.
- `pages/about.html` و`pages/contact.html`: صفحات تعريف وتواصل.
- `js/doctors-data.js`: مصدر البيانات الموحد للمدن والمناطق والأطباء.
- `css/style.css`: التنسيقات العامة.

## البحث والفلاتر
تُنشأ البيانات في مصدر مشترك يضم 8 مدن، و4 مناطق لكل مدينة، و4 أطباء لكل منطقة (128 طبيبًا). تعرض الصفحة الرئيسية كل التخصصات الستة عشر الموجودة في مصدر البيانات نفسه. تحتوي صفحة الأطباء على أربعة فلاتر فقط: المدينة، والمنطقة (وتتغير الخيارات حسب المدينة)، والتخصص، والحد الأدنى للتقييم. يمكن للصفحة الرئيسية تمرير التخصص والمنطقة إلى صفحة النتائج عبر الرابط.

## تنبيه بشأن الحجز والحسابات
الحجز تجربة واجهة فقط؛ لا يتم إرسال البيانات إلى أي جهة ولا يُسجّل الموعد فعليًا لدى عيادة. حسابات الدخول تجريبية داخل جلسة المتصفح الحالية فقط، ولا يتم حفظ كلمات المرور. لا تستخدم هذه الواجهة لإدخال بيانات شخصية حقيقية.
